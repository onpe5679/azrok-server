## 4. 음식 → 스탯 / 약 → 질병

- 음식 효과 = 허기 상승. Azrok.dat 의 value 는 **가격**(품질 티어)이지 허기량 아님. 실제 허기 델타 = sys.tmp(content/65 "식사" 그룹 허기+40~50), 아이템→액션 executor(content/69) 경유.
- 약 = 특정 질병 플래그 제거(스탯 회복 아님). 치료 대상 질병 스탯 인덱스는 desc 텍스트만 확인(미확정).

## 5. 질병 시스템 — 데이터 레이어 (2026-07-18 갱신)

- **질병 6종 ↔ 약 6종 (VERIFIED, Azrok.dat 파일 바이트):** 각 약 레코드 = name(`XX약`) + effect-desc(`XX치료`) + price.
  경증(감기/두통/위장)=70골드, 중증(독감/신경병/위염)=200골드. price 는 문자열 뒤 u32로 직접 확인
  (감기치료 after=0x46=70, 독감치료 after=0xc8=200 …). 6종 전부 domain6.
- **★ 질병은 lgc.tmp 57스탯에 없음 (VERIFIED — 네거티브):** 이번 세션에서 lgc.tmp 57행 스키마 전체를
  덤프(stat0 IQ … stat56 펫)했으나 감기/독감/두통/신경병/위장/위염 어느 것도 스탯으로 존재하지 않음.
  → **질병 상태는 57-스탯 배열(`logic+0x5f4`)이 아니라 별도 런타임 필드/플래그로 추적됨.** 약 레코드에도
  숫자 질병-id 필드 없음(name/desc 문자열 + 아이템ID 순서로만 질병 구분). 즉 "약 사용 → 특정 질병 플래그 clear".
- **발병 트리거 텍스트 없음 (VERIFIED — 네거티브):** 덤프한 문자열에 발병/증상/걸림 관련 메시지 부재
  (스트레스 관련은 '수면시 …스트레스 5감소'만). → 질병 UI 는 이미지 기반이거나 발병이 무음 스탯구동 추정(INFERRED).
