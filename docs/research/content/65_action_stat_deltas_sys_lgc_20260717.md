## 3. 미니게임 → 스탯 매핑 (quest-minigame VERIFIED + lgc.tmp 교차검증)

Gym 팝업 소비자 `FUN_005E3EE0` cmd 라우팅 → stat 배열 오프셋:
- **팔굽혀펴기 0x41 → stat 31 (0x1F)**, **아령 0x42 → stat 32 (0x20)**, **줄넘기 0x43 → stat 33 (0x21)**
- 장난감 key 0x71: 저글링/요요/덤블링 → 34/35/36 (0x22–0x24)
- 마법 key 0x72: 매직클론/퍼니쉴드/에어훅 → 37/38/39 (0x25–0x27)
- 스탯 저장 = `*(logic+0x5f4)` 71-entry array, stride 0xC (idx = offset/0xC). idx9 max는 진화 게이트(500/600/700).
- 델타 양(각 +3)은 sys.tmp 운동 그룹에서 확인. **정적 스탯 인덱스(Ghidra) ↔ lgc.tmp 이름 순서 ↔ sys.tmp 델타가 3중 일치.**
