## 정적 UI 경로

`FUN_005B7AD0`은 `Condition_Box.wis` 에너지 슬롯을 engine 좌표 `(504,390)`에 만들고 main button id `0x104`를 부여합니다. `CGameButton::MouseDown@0051B140`과 `MouseUp@0051B390`은 같은 hitbox 안의 단일 좌클릭 down/up을 처리합니다. 더블클릭이나 드래그는 필요하지 않습니다.

상위 소비자 `FUN_005BAF60`은 event type/param2가 `2`일 때 `0x104..0x107`을 `FUN_005BC970(...,2)`로 보냅니다. slot0의 full item id는 `5000`, C2S payload는 `5000-5000=0` 한 바이트입니다.

## 동적 절차와 입력 경계

격리 namespace `profile_minimal`의 Ener103에 정당한 서버 구매로 energy item5000 1개를 준비했습니다. canonical 시작값은 energy0=1, currency=1000, SHA-256 `0B0E5D0E...A8F0CC`였습니다.

원본 화면의 정확한 슬롯 중심 `(527,435~436)`에 elevated real single-click을 보냈지만 CGameButton queue와 wire에는 이벤트가 없었습니다. 이는 현재 자동 입력 계층이 게임 내부 down/up sampler를 통과하지 못한 증거이며 서버 item-use 실패 증거가 아닙니다.
