## ★ 진화 5단계 — 우리가 아는 4단계 위에 **화이트론(알)과 미지의 5단계**가 있다
- 내용(요약; 원문은 위 출처 문서의 각주를 볼 것):
  - 위키는 아즈론이 총 5단계까지 성장하며 공식 자료에 나온 모습은 모두 4단계 기준이라고 적는다.
  - 단계 순서는 알(화이트론) → 블루론 → 레드론 → 실버론 → 골드론 → 미공개 5단계로 정리돼 있다.
  - 공식 사이트가 5단계 모습을 실루엣으로만 보여 줘서, 서비스가 끝날 때까지 5단계 모습을 아는 사람은 없었다고 한다.
  - 레벨업이 매우 어려워 실버론 이후 성장이 힘들었고, 골드론이 되려면 특정 미션을 깨야 했으나 사실상 불가능했다는 각주가 있다.
- **우리 확정 사실과의 정합**: docs 106 의 `블루론0 → 레드론1 → 실버론2 → 골드론3`. 위키의 "골드론=4단계"는 **1-based 카운트**이고 우리 값은 0-based다 → **완전히 일치**한다.
- **★ 파생 액션 아이템 (검증 필요, NOT VERIFIED)**:
  1. 진화 단계값 **4**(= 위키가 말하는 미지의 5단계)에 해당하는 엔트리가 클라이언트 데이터/모델에 존재하는지 확인할 것. 존재한다면 **아무도 본 적 없는 콘텐츠를 우리가 최초로 복원**하는 셈이다.
  2. 알 상태 **화이트론**이 데이터에 있는지(진화 -1 또는 별도 상태). 우리 진화 축은 블루론부터 시작한다.
  3. "골드론 진화에 필요한 특정 미션"이 무엇인지 — 퀘스트 테이블에서 확인 가능할 수 있다.
- 주의: 위키 서술이므로 **단독 근거로 단정 금지**. 반드시 바이너리/데이터로 직접 확인할 것.
