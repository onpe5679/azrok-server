## 누락으로 오판하면 안 되는 항목

- 귓속말은 이름별 recipient 선택 코드가 있습니다(`azrok_server.py:6526`).
  소셜/정보 관련 로컬 테스트7개가 통과했습니다. 친구 목록은 원본 기능 존재부터 미확인입니다.
- toy/gym000D/E의 dormant 표시는 현재 원본 송신 도달성에 관한 구분입니다.
  `_process_item_use:9206`에는 소유권 검증과 저장 구현이 실제로 존재합니다.
- S2C00D1은 원본 dispatcher에 없는 금지 opcode입니다. 미구현 기능으로 채울 대상이 아닙니다.
- C2S000B는 의미 자체가 미확정입니다. 무응답은 확인되지만 사용자 기능명을 붙일 수 없습니다.
- 레드론 level3 직후 빈 성장 퀘스트는 #652의 level10 조건과 일치합니다.
- 일반 퀘스트 및 후기 성장의 실제 UI 전수 수용, 시설7종 퇴장 전수 수용은
  **NOT VERIFIED**입니다(#602/#592). 미검증을 곧 구현 누락으로 분류하지 않습니다.
