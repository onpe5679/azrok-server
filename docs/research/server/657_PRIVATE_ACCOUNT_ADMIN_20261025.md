# 657 — Tailscale 계정 관리 화면 (2026-10-25)

기존 관제실의 계정 관리 버튼에서 계정/캐릭터 검색, 최근 접속순 정렬,
저장 정보·스탯·퀘스트 조회, 펀콘 및 인벤토리 수정, 백업 삭제,
접속·채팅·관리 이력을 제공합니다.

## VERIFIED: 구현과 테스트

- 최근 접속은 인증된 로그인 이벤트로 수집합니다. 과거 이력이 없는 계정은
  최근 저장 시각을 별도로 표시하며 접속 시각이라고 부르지 않습니다.
- 채팅·로그인·종료 이력은 계정/캐릭터 키에 연결된 별도 JSONL에 저장합니다.
  비밀번호/토큰/원본 로그인 패킷은 넣지 않습니다. 최근8MiB/최대200건의
  표시 한계와 손상 행은 UI에서 밝힙니다. 과거 채팅 소급 수집은 하지 않습니다.
- 인벤토리 검색·분류·보유만 필터는 편집 중 값을 보존합니다. 예약 슬롯은
  변경 불가, 고유 소지품은0..1, 일반 수량은0..255입니다.
- 접속 중 계정은 수정/삭제하지 않습니다. proto 및 OX 작업 잠금 안에서
  revision을 재확인하고 캐릭터별 원본 백업 후 canonical 저장을 수행합니다.
  삭제는 보관 이동이며 원본과 receipt가 admin_backups에 남습니다.
- 업데이트/삭제는 JSON과 동일 출처를 요구합니다. 공개 게임 서버에는
  관리 API를 연결하지 않습니다. Tailscale Serve HTTPS9300을 기존
  loopback9300에 연결했고 기존 tailnet서비스 설정은 유지했습니다.
- 실제 서버/HTTP 통합13개 및 전체363개 테스트 통과. 임시 저장소에서
  실제 브라우저로 펀콘500→600, 이유식0→2, revision 증가 및 채팅/변경
  이력 표시를 확인했습니다. `artifacts/20261025_admin_ui_verified.png`.

접속: `https://<tailnet-host>:9300/admin` (tailnet 전용, 관리 화면 바로가기).
수정 파일: azrok_control.py, azrok_control_page.py, azrok_admin.py,
azrok_admin_service.py, azrok_admin_history.py, 서버 로그인/이벤트 기록 훅.
새 모듈은 sync_to_u32ws.ps1 배포 목록에 등록했습니다.

## 표시와 기능의 한계

성장단계/레벨/스탯/퀘스트는 조회 전용입니다. 임의 수정이 원본 진행 조건과
충돌하지 않도록 일반 편집은 펀콘과 확인된 인벤토리 범위로 제한합니다.
고유 아이템 이름이 확인되지 않은 항목은 한국어 분류/슬롯/ID로 표시합니다.
이유식1000은 검증된 이름입니다. 재접속 후 인벤토리 적용의 원본 게임 GUI는
이번 관리 화면 테스트와 별개의 검증입니다.
